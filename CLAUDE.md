# CLAUDE.md

Two disjoint git lineages by design, and the names differ by where you stand. In this checkout, local `main` is the dev lineage (published to the remote as `recovery/operator-os-explainer-main-20260719`) and local `release` is the release lineage, published to the remote as `main`, which the public site serves. The two share no merge base. Publishing copies a tree from dev onto `release`; never merge, rebase, or cherry-pick between them, and do not read the missing merge base as a broken repo. Whether the dormant dev branches stay on the public remote is the operator's decision; do not resolve it. Details in RELEASE.md; design sources live in the sibling operator-os-explainer-design directory.
